# Groupe1-Sujet20
## Travail Attendu
### Construire dans Microsoft Fabric un modèle de Machine Learning répondant à un cas d’usage métier clairement défini. Préparer les données nécessaires, entraîner et évaluer le modèle à l’aide d’indicateurs pertinents, puis générer des prédictions ou des scores exploitables. 
### Intégrer ensuite ces résultats dans Power BI afin de permettre aux utilisateurs de les analyser selon plusieurs axes, de les comparer aux données réelles et d’identifier les facteurs qui influencent les résultats. 
### Le groupe devra documenter le processus de bout en bout, justifier les choix méthodologiques, présenter les limites du modèle et proposer un mécanisme simple d’actualisation des prédictions.
